Setelah tersambung, setiap kali file ini dibuka (atau klik ⟳ Muat ulang) data diambil langsung dari Google Sheets — tidak perlu buat ulang HTML.

  2. Tempel isi file Code.gs → Save
  3. Deploy → New deployment → Web app, Execute as: Me, Who has access: Anyone
  4. Salin Web app URL (berakhiran /exec) lalu tempel di bawah
